# BepInEx

A custom build of BepInEx indended only for debugging Plate Up! mods.  This build targets the same version `2.13.0` of of HarmonyX as the one used in the official [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=2898033283&searchtext=harmony).  This is NOT needed to run Plate Up! mods as mods are offically supported in the Steam Workshop.
